# Sampad Karmaker — Personal Portfolio

Responsive portfolio built with HTML, CSS and vanilla JavaScript (MERN 19, Module 4 assignment).

**Sections:** Navbar, Hero, About, Skills, Projects, Education, Contact (form), Footer.

## Run
Open `index.html` in a browser, or enable GitHub Pages on the `main` branch.

## Structure
- `index.html`
- `style.css`
- `script.js`
- `images/` (profile photo and project screenshots)
